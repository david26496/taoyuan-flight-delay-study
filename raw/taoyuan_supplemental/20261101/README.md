# 補充航班資料

使用者提供，表示資料來源已確認；本次未獨立驗證來源及實際收集時間。原始檔名與內容逐位元保留。檔名的時間及時區未經查證，不應假設為既有系統的收集時間。

`valid/` 為 UTF-8 編碼的 20 欄進出港航班紀錄；`excluded/` 保存空檔與 HTTP 522 錯誤頁，不應用於航班分析。`manifest.json` 記錄每個檔案的 SHA-256、大小及結構檢查結果。

這些資料由他人提供，並非本專案 collector 自動收集；未偽造 collector 日誌。既有系統資料採 CP950 編碼，故補充檔獨立存放，現有處理程式不會自動納入；分析時需明確選用並以 UTF-8 讀取，再處理跨快照重複紀錄。
